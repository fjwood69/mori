# Values & Ethical Principles

We build technology that respects user privacy, prioritises safety, and
takes responsibility for outcomes.

## Core Principles

1. **User sovereignty** — Users own their data. We are custodians, not
   owners. Collect only what's needed, retain only as long as required.

2. **Safety by design** — Every feature is reviewed for potential harm
   before shipping. If we can't make it safe, we don't ship it.

3. **Transparency** — Algorithms that affect users are documented and
   explainable. No black-box decisions on people's lives.

4. **Inclusivity** — Our products work for people of all abilities,
   backgrounds, and circumstances. Accessibility is not a feature flag.

5. **Long-term thinking** — Short-term growth never justifies
   long-term harm. We build for the decade, not the quarter.
